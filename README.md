# Somma Media (local development)

This repository is a Vite + React project scaffolded originally with a third-party tool. It has been adjusted to run locally without that service.

Getting started

1. Install dependencies:

```sh
npm install
```

2. Start the dev server:

```sh
npm run dev
```

3. Build for production:

```sh
npm run build
npm run preview
```

Notes

- Environment variables for Supabase live in `.env` (do not commit secrets).
- If you previously relied on a third-party service for deployment, use your own hosting (Vercel, Netlify, etc.) or deploy via the usual Vite build output.
